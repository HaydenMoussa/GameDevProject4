# Throw Wonder

## Intent
The intent of our game "Throw Wonder" is to create a 3D world with dynamic player and object movement, while incorporating challenging gameplay

## Narrative
The player character is a man known as the "Throw Wonder" and works for "The Boss," who can be seen and spoken to when the game opens. The player has to throw object into the correct goals within a time limit, and will be fired if they run out of time.

## Mechanics
WASD is used to move, E is used to interact with the NPC and to pick up objects, the mouse is used to look around and aim, and right mouse click is used to throw.

## Aesthetics
We wanted this game to give medival/circus performance vibes.

## Joys and Struggles

### Eden's POV
A big struggle for me was troubleshooting textures. Since I collected models for the environment, it was my problem when the vast majority of them didn't seem to want to load. Thankfully, we were able to recover textures for the most important things. Additionally, I once again enjoyed composing music for the game, although I wish I had more time to polish the track or to make more for the score.
### Hayden's POV
I had previously only worked in 2D games and I had spent a lot of time working on mechanics using 2D vectors and stuff. So it was refreshing to work in the new 3D enviorment on movement. A struggle I had was colliders, in particular I found it hard to position the coliders in the correct spot around the game objects.
### Leigh's POV
I always really enjoy coming up with the narrative/story for games, and that was definitely the case with this one. Figuring out how to get the NPC added was also fun. Moving from 2D game design to 3D was definitely aa slight challenge, especially trying to design the world, and I had some merge issues along the way.
